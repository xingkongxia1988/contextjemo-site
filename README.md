# ContextJemo Site

contextjemo.com / contextjemo.cn 的产品介绍站（双语）。

- 根路径 `/` = 英文（国际站）
- `/cn/` = 中文站
- 部署：GitHub Pages（`gh-pages` 分支），`CNAME` = `contextjemo.com`

## 目录

```
index.html            英文首页（contextjemo.com 根）
cn/index.html         中文首页（contextjemo.cn / contextjemo.com/cn/）
assets/css/site.css   设计系统（6 档字阶 / 10 档间距 / 1 强调色·琥珀）
assets/js/site.js     导航 + 滚动显现
assets/logo/          favicon
```

## 设计约束（源自 design/creed.md）

1. 版面主体只用真实产物（AET YAML、内核红线、确认事件），不画气氛线条
2. 6 档字阶、10 档间距、1 个强调色（琥珀）
3. 宋体（--serif）只出现在 `.sheet` 纸面段
4. 琥珀只出现在两处：主 CTA 底色、trace id 文字

## 改文案注意

站内所有代码块均为仓库真实文件片段，改动前先核
`FlashJemo-RheaLite/tactics/` 与 `FlashJemo-RheaLite/.kernel/`。
